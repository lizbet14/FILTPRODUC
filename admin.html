Configurar publicación

Para publicar cambios para todos, la web guarda en tu repositorio de GitHub. Necesita un token que se crea una sola vez:

  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → FILTPRODUC.
  3. Permissions → Repository permissions → Contents (Contenidos): cambia "Read-only" por Read and write (Lectura y escritura). Viene en solo lectura por defecto.
  4. Genera el token y pégalo aquí.

Se guarda cifrado con tu clave solo en este navegador. Nunca se sube a la web.

Cambiar clave

La nueva clave se publica en la web (solo su hash) y reemplaza a la actual. Necesita la publicación configurada.

Mínimo 10 caracteres, con letras y números.
